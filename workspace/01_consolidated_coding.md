# Consolidated Codebook - 密码安全用户研究

Please review the merges below. If a merge is incorrect, you can edit this file.

### [x] CC_001: The practice of classifying accounts...
**Definition**: The practice of classifying accounts based on perceived risk or asset value (e.g., banking vs. forums) and applying different levels of password complexity or management effort accordingly.
- **Evidence**:

  - (P01): "银行卡那是6位数字密码，那个肯定不一样... 其他的网站，只要不是很重要的，我就随便设个简单的。"

  - (P02): "看情况。如果是重要的，比如工作账号，我会由两个常用的单词组合加上当前的年份。如果是一次性的网站，就浏览器自动生成一个强密码"

  - (P02): "设计了分级的。T1 是银行、主邮箱、微信，用最复杂的且不重复的。T2 是京东、美团这种，用另一套。T3 就是各种论坛"

<!-- END: CC_001 -->


### [x] CC_002: A heuristic strategy where users...
**Definition**: A heuristic strategy where users create or update passwords by applying predictable transformations (e.g., appending numbers, capitalization, or dates) to a base string or previous password, often to satisfy system requirements.
- **Evidence**:

  - (P01): "就还是用我那个老密码呗，后面加个1或者2。如果是必须要大写字母，我就把首字母大写。"

  - (P02): "这只会逼着用户把密码改成 Password01, Password02。我每次遇到这种强制要求都很反感，只能被迫用一些规律性的变化。"

<!-- END: CC_002 -->


### [x] CC_003: The intentional use of a...
**Definition**: The intentional use of a single master password or a limited set of passwords across multiple accounts, typically applied to low-risk services to reduce cognitive load.
- **Evidence**:

  - (P01): "反正我记不住那么多密码，基本都是一个主密码变来变去。"

  - (P02): "T3 就是各种论坛，基本全一样，丢了也无所谓。"

<!-- END: CC_003 -->


### [x] CC_004: A strong desire to replace...
**Definition**: A strong desire to replace knowledge-based authentication (passwords) with possession or inherence factors (biometrics, SMS, Passkeys) to improve convenience and reduce cognitive burden.
- **Evidence**:

  - (P01): "反正现在都能手机号登录，密码基本也就是个摆设。"

  - (P01): "人脸识别我也开，主要是不是为了安全，是为了方便，不用输密码了嘛。"

  - (P01): "最好就是不用密码，走哪里都刷脸... 别让我动脑子去记那些乱七八糟的字符。"

  - (P02): "就是像现在的 Passkey（通行密钥）那样吧。不需要密码，直接生物识别验证。"

<!-- END: CC_004 -->


### [x] CC_005: The reliance on unencrypted, external...
**Definition**: The reliance on unencrypted, external memory aids to store credentials, including physical notes or plain-text digital memos (e.g., note-taking apps), posing a security risk.
- **Evidence**:

  - (P01): "所以我现在都把新改的密码写在手机备忘录里，不然根本记不住。"

  - (P02): "我是直接写在便签纸上贴在家里 iPad 背面。"

  - (P03): "记在了一张纸条上放在保险柜里，以防我失忆。"

<!-- END: CC_005 -->


### [x] CC_006: A state of exhaustion or...
**Definition**: A state of exhaustion or indifference towards security hygiene, characterized by ignoring alerts or failing to update credentials after a breach due to the perceived effort required.
- **Evidence**:

  - (P01): "我就申诉找回来了，也没改密码，太麻烦了。"

  - (P01): "收到过，但我看了一眼，也不知道是真是假，就没管。反正到现在号也能用，应该没事吧。"

<!-- END: CC_006 -->


### [x] CC_007: The decision to stop using...
**Definition**: The decision to stop using a service or abandon an account creation process because the authentication or recovery procedures are perceived as too burdensome or restrictive.
- **Evidence**:

  - (P01): "最后它说我账号被锁定了，让我找客服。我一气之下就注册了个新的，不登了。"

  - (P01): "我觉得太麻烦了，有时候为了看个文章还得注册，我就直接关了不看了。"

  - (P03): "如果没有... 那就说明我没注册过，或者当时注册那个号太不重要我都没存。没存的话基本就放弃了"

<!-- END: CC_007 -->


### [x] CC_008: The practice of sharing account...
**Definition**: The practice of sharing account credentials through social messaging platforms, ranging from plain text transmission to obfuscated methods (e.g., retracting messages), often bypassing secure sharing tools.
- **Evidence**:

  - (P01): "视频会员经常借给朋友。我就直接微信发过去呗。"

  - (P02): "线上发的话，发完我会撤回，或者分两段发。"

<!-- END: CC_008 -->


### [x] CC_009: The use of dedicated software...
**Definition**: The use of dedicated software or browser-based tools to store, manage, and autofill credentials, shifting the user's task from memorization to management.
- **Evidence**:

  - (P02): "先看 Chrome 浏览器有没有记住。如果记住了就直接填充。"

  - (P03): "我用 1Password 管理，里面记录了大概 350 多个条目。"

<!-- END: CC_009 -->


### [x] CC_010: User frustration with and skepticism...
**Definition**: User frustration with and skepticism towards policies requiring periodic password changes, often viewed as 'security theater' that induces cognitive overload without adding real security.
- **Evidence**:

  - (P01): "每次强制改密码，我都得想半天，改完了下次肯定忘。"

  - (P02): "定期更换是最愚蠢的策略。NIST 早就说不推荐定期更换了。"

  - (P03): "定期更换也是，毫无意义的安全剧场。"

<!-- END: CC_010 -->


### [x] CC_011: Dissatisfaction with inconsistent or rigid...
**Definition**: Dissatisfaction with inconsistent or rigid password complexity requirements (e.g., character limits, symbol restrictions) that conflict with password managers or user heuristics.
- **Evidence**:

  - (P02): "很多网站的密码规则太奇葩了，有的不让用特殊符号，有的限制长度... 这我就很不理解"

  - (P03): "这种规则对真正的密码管理器用户很不友好。有时候生成的随机密码不符合它的规则"

<!-- END: CC_011 -->


### [x] CC_012: The strategy of generating long...
**Definition**: The strategy of generating long, random, and unique character strings for every account, typically relying on software to handle the complexity and lack of memorability.
- **Evidence**:

  - (P03): "生成 20 位随机字符，保存，填入。"

  - (P03): "我根本不知道那个密码是啥。"

  - (P03): "每一个，我是说每一个账号，密码都不一样。因为全是随机生成的。"

<!-- END: CC_012 -->


### [x] CC_013: A specific preference for using...
**Definition**: A specific preference for using hardware tokens or authenticator apps over SMS-based verification, driven by perceptions of higher security or reliability.
- **Evidence**:

  - (P02): "只要支持 2FA 的我都开。特别是 Google Authenticator，比短信安全。"

  - (P03): "我不用短信验证码，不安全。我用 YubiKey 这种硬件 Key，或者 Authy 这种 APP。"

<!-- END: CC_013 -->


### [x] CC_014: User difficulties arising from poor...
**Definition**: User difficulties arising from poor integration between password management tools and operating systems or specific applications, leading to manual copying/pasting.
- **Evidence**:

  - (P03): "希望操作系统层面能打通，不管是在 PC 浏览器还是手机 APP，都能一键识别并填充。"

  - (P03): "国内很多 APP 不支持标准的密码填充 API，导致还要手动切出去复制粘贴，体验极差。"

<!-- END: CC_014 -->


### [x] CC_015: The prioritization of security behaviors...
**Definition**: The prioritization of security behaviors specifically to protect financial assets, often treating non-financial data as negligible.
- **Evidence**:

  - (P01): "钱吧，肯定怕钱被转走。至于聊天记录啥的，也没啥见不得人的，不怕看。"

<!-- END: CC_015 -->


### [x] CC_016: The cognitive bias where users...
**Definition**: The cognitive bias where users believe they are unlikely to experience a security breach or cyberattack personally.
- **Evidence**:

  - (P01): "听说过啊，新闻里老说。但我感觉跟我没啥关系，我也没什么钱。"

<!-- END: CC_016 -->


### [x] CC_017: The awareness that compromising a...
**Definition**: The awareness that compromising a central account (e.g., email) can lead to a 'domino effect' compromising all linked services.
- **Evidence**:

  - (P02): "主邮箱被盗。因为很多其他账号都能通过邮箱找回密码。一旦邮箱丢了，就像多米诺骨牌一样全完了。"

<!-- END: CC_017 -->


### [x] CC_018: The active use of third-party...
**Definition**: The active use of third-party tools (e.g., HaveIBeenPwned) to check for credential exposure following news of data leaks.
- **Evidence**:

  - (P02): "现在看到那种大规模泄露的新闻，我会去 HaveIBeenPwned 查一下。"

<!-- END: CC_018 -->


### [x] CC_019: The permanent loss of access...
**Definition**: The permanent loss of access to digital assets or memories resulting from the inability to recall credentials or recovery answers.
- **Evidence**:

  - (P02): "死活想不起来，密保问题的答案也忘了。最后只能放弃，里面的照片估计也没了。"

<!-- END: CC_019 -->


### [x] CC_020: The belief that secure tools...
**Definition**: The belief that secure tools (like password managers) are too difficult for the average person to learn or set up.
- **Evidence**:

  - (P03): "但由于上手门槛太高，他们基本都不用。"

<!-- END: CC_020 -->


### [x] CC_021: The use of dedicated security...
**Definition**: The use of dedicated security features (e.g., family vaults) to share credentials, contrasting with ad-hoc methods.
- **Evidence**:

  - (P03): "我用 1Password 的家庭共享功能。把需要的条目放到共享保险库里"

<!-- END: CC_021 -->
